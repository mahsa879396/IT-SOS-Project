🐞 Challenges & Debugging JourneyIssue 1: Server Unreachable (ERR_CONNECTION_REFUSED)Symptom: Browser failed to load http://localhost:3000 with connection refused error.   Root Cause: Port mismatch during startup. The application server script was configured to run on port 5000 rather than the standard port 3000.Resolution: Corrected browser target URL to http://localhost:5000 and aligned port configurations in server.js.Issue 2: Unhandled Root Endpoint (Cannot GET /)Symptom: Opening http://localhost:5000 resulted in an explicit default Express error Cannot GET /.   Root Cause: The server lacked a static directory mapping or an explicit route handler for the root path (/) to resolve index.html.   Resolution: Integrated path module and added static middleware:JavaScriptapp.use(express.static(__dirname));
app.get('/', (req, res) => {
    res.sendFile(path.join(__dirname, 'index.html'));
});
